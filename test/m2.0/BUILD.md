# DARK ARENA — тестовая сборка M2.0 HEAVY ARSENAL (GitHub Pages)

Снимок `prototype-3d/` с тега `m2.0` (коммит 88bae99, ветка `claude/m2.0-heavy-arsenal`) — три вида оружия: DA-R1 RAVEN,
AK-47 MOD, помповое ружьё DA-S12 KRAIT; смена оружия (ПК: 1 / 2 / 3 и колесо мыши; iPhone: слоты в верхней полосе HUD),
тактический фонарик (ПК: L; iPhone: кнопка «СВЕТ»), эффекты попаданий, удар прикладом для всех видов оружия.
Только для тестирования; стабильная версия игры (`index.html` в корне), папки test/m1.4 … test/m1.9 и `topdown/`
не изменялись. Не принята до проверки на настоящем iPhone.
Отчёт: docs/M2.0-REPORT.md в ветке `claude/m2.0-heavy-arsenal`.
