# DARK ARENA — тестовая сборка M3.0 TOPDOWN PLAYABLE (GitHub Pages)

Снимок `prototype-3d/` с ветки `claude/m3.0-topdown` (коммит 1a7b589, основа — M2.0 `88bae99`): первая играбельная
3D-версия с камерой сверху под 55°. Модели героя и трёх видов заражённых (ходок, громила, мутант) предоставлены
владельцем. Управление: iPhone — левый джойстик движение, правый прицел (дальше от центра — огонь), РЫВОК / ПЕРЕЗ. / ОРУЖ.;
ПК — WASD, мышь, ЛКМ, R, Пробел, 1/2/3. Три волны.
В этом снимке `index.html` = `topdown.html` (вход top-down); FPS-версия M2.0 — в `test/m2.0/`.
Только для тестирования; стабильная версия игры (`index.html` в корне), `topdown/` и папки test/m1.4 … test/m2.0
не изменялись. Не принята до проверки на настоящем iPhone. Отчёт: docs/M3.0-REPORT.md в ветке `claude/m3.0-topdown`.
