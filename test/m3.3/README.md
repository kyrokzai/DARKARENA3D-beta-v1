# DARK ARENA — тестовая сборка M3.3 TOPDOWN GAMEPLAY (GitHub Pages)

Снимок `prototype-3d/` с ветки `claude/m3.3-gameplay` (основа — M3.2 PREMIUM). Вход: `index.html` = `topdown.html`.
Новое: бесконечное выживание после 3-й волны, очки и комбо, экран итогов и рекорд по очкам, дроп аптечек и патронов.
Только для тестирования; стабильная версия игры (`index.html` в корне) и папки test/m1.4 … test/m3.0 не изменялись.
Не принята до проверки на настоящем iPhone. Отчёт: docs/M3.3-REPORT.md в ветке `claude/m3.3-gameplay`.
