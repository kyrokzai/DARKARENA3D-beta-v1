# DARK ARENA — M3.3 TOPDOWN GAMEPLAY (этапы 1–2) — отчёт

Ветка `claude/m3.3-gameplay` (база: `claude/m3.2-premium`, точка восстановления — тег `m3.2-base-restore` локально / коммит базы).
Утверждено владельцем: этап 1 (бесконечное выживание + очки / комбо + экран итогов) и этап 2 (дроп аптечек и патронов).
Этапы 3 (граната) и 4 (прокачка между волнами) **не делались**.
FPS-версия не менялась: все новые механики — опции `Game`, выключенные по умолчанию (правило 17/19), проверено тестами.
**Не принято**: эмуляция iPhone в Chromium ≠ реальный iPhone; нужна проверка на устройстве (чек-лист ниже).

## Что сделано

| Блок | Что |
|---|---|
| Бесконечное выживание | После 3 сценарных волн матч продолжается. Волна n ≥ 4 = `topdownEndlessWave(n)` (`wave-defs.js`): ходоки 4 + n, мутанты 1 + ⌊(n−1)/2⌋, громилы 1 + ⌊n/2⌋; одновременно живых 6 + ⌊(n−3)/2⌋ (≤ 10); интервал появления 1,1 − 0,06·(n−3) с (≥ 0,6 с). Характеристики заражённых не растут (правило 10). Экрана «Победа» в top-down больше нет — забег заканчивается смертью. Пополнение патронов и +30 HP между волнами как раньше |
| Очки и комбо | `sim/score.js` (данные): ходок 100, мутант 200, громила 300; хедшот +50 %, убийство прикладом +50 %; комбо — каждое убийство в течение 3 с после предыдущего, множитель +0,25 за убийство, максимум ×3; бонус за зачищенную волну 250 × номер. Пишется в `GameState.score`, HUD только читает (правило 8). После смерти очки не начисляются |
| Точность | `GameState.stats`: выстрел = 1 патрон (дробь KRAIT = один выстрел), попадание = патрон, задевший цель |
| HUD | «Волна N» без «/3»; плашка «ОЧКИ» под счётчиком волны; индикатор комбо (множитель, длина, полоса окна); всплывающие «+150 · В ГОЛОВУ», «ВОЛНА +1 000»; тост подбора «+25 HP» / «+60 патронов»; задача «Продержаться: N волн» |
| Экран итогов | Очки крупно, «НОВЫЙ РЕКОРД», «Застава держалась N волн. Погибли на волне M», сетка: волна, убито, время, точность, лучшее комбо, хедшоты; влезает в 390 px высоты |
| Рекорд | Лучший результат по очкам (localStorage, тот же ключ `darkarena.topdown.v1`); старый рекорд M3.2 без очков считается 0 очков. В профиле меню: «Рекорд: 14 488 · волна 5» |
| Дроп | `sim/pickups.js`: ходок — аптечка 8 % / патроны 16 %; мутант 16 % / 24 %; громила — всегда одно из двух (50/50). Предмет падает на месте смерти (или рядом, на свободный пол), подбирается подходом (1,1 м), лежит 15 с, последние 4 с мигает, на полу максимум 8 (старый исчезает). Аптечка +25 HP — только если ранен; патроны +1 магазин в запас **каждому** оружию, не выше полного запаса — только если есть куда. Иначе предмет остаётся лежать |
| Визуал дропа | `topdown/pickups-view.js`: собственная процедурная геометрия (правило 3) — светлый кейс с зелёным крестом / оливковый ящик с латунными патронами, кольцо свечения на полу (аддитивное), покачивание и вращение, вспышка-кольцо при подборе. InstancedMesh: ≤ 5 draw calls при любом числе предметов, 0 при пустом поле. Новых источников света нет (правило 12) |

## Найдено и исправлено по ходу
1. **Задачи «Уничтожить громил / мутантов» в M3.2 никогда не показывались**: HUD читал `wave.groups`, а у волн поле `enemies`. Исправлено; теперь счёт идёт по всем волнам до текущей (включая бесконечные).
2. **Рекорд не показывался в меню после перезагрузки страницы** (M3.2): текст профиля обновлялся только при возврате в меню. Теперь — сразу после загрузки.
3. На iPhone (844 × 390) очки в строке волны наезжали на панель «Текущая задача» — вынесены в отдельную плашку, тест проверяет отсутствие пересечений.

## Как проверить
**ПК**: `python3 -m http.server` в корне репозитория → `http://localhost:8000/prototype-3d/topdown.html`
(или тестовая сборка на Pages: `test/m3.3/`).

**iPhone (горизонтально)**:
1. «Играть» → в HUD «Волна 1» и плашка «ОЧКИ 0» под ней; ничего не перекрывает задачи и профиль.
2. Убейте несколько заражённых подряд — растут очки, появляется «×1,25 · КОМБО 2…» с убывающей полосой; через 3 с без убийств комбо гаснет.
3. С заражённых иногда падают аптечки (белый кейс, зелёный крест) и патроны (оливковый ящик); с громилы — всегда. Подойдите: при ранении аптечка лечит, тост «+25 HP»; при полном здоровье остаётся лежать. Через 11 с начинает мигать, через 15 с исчезает.
4. После 3-й волны игра продолжается (волна 4, 5…), врагов больше, громилы и мутанты чаще.
5. Смерть → экран итогов: очки, «НОВЫЙ РЕКОРД», сколько волн продержались, точность, комбо. Влезает в экран, кнопки нажимаются.
6. «Главное меню» → в профиле «Рекорд: … · волна N»; закройте и откройте страницу — рекорд на месте.
7. Сообщите: не тормозит ли на поздних волнах (до 10 живых заражённых), не мешают ли всплывающие очки обзору, нравится ли баланс дропа.

## Ограничения / не сделано
- Нет проверки на реальном iPhone; производительность поздних волн (до 10 живых) на iPhone 11 не измерена — в эмуляции контейнера она не показательна.
- Баланс (очки, шансы дропа, рост волн) — первый вариант, все числа в данных (`score.js`, `pickups.js`, `ENDLESS`) и меняются одной строкой.
- Экран «Победа» в top-down не используется (разметка оставлена, правило 5).
- Звуки подбора — существующие звуки (вставка патрона / доставание оружия), отдельных нет.
- Граната и прокачка — этапы 3–4, не начаты.
