# Этап M1.2 — игровой HUD

Дата: 9 ноября 2026 · Ветка: `claude/m1.2-gameplay-hud` (от тега `m1.1`) · Всё локально, GitHub не использовался.
Основная игра BUILD 1.1–1.3 не изменялась (diff по трём файлам — 0 строк; тесты 1.3 — 34/34).

## Что сделано

| Требование | Реализация |
|---|---|
| Здоровье 100 HP | Панель: иконка, сегментированная полоса (10 делений), число |
| Плавное уменьшение | Полоса падает за 0,18 с, за ней красный «шлейф» догоняет через 0,35 с — урон читается с одного взгляда |
| Критическое HP | ≤ 50 % — янтарный цвет; **≤ 25 %** — красная пульсирующая полоса и число + пульсирующая красная виньетка по краям экрана; при каждом уроне — короткая красная вспышка |
| Патроны 30/120 | Крупно — магазин, мельче — запас; ≤ 30 % магазина — янтарный |
| Перезарядка | «ПЕРЕЗАРЯДКА» + полоса прогресса; пустой магазин — «ПЕРЕЗАРЯДИ» (красный), нет патронов — «НЕТ ПАТРОНОВ» |
| Номер волны | «ВОЛНА N»; баннер «ВОЛНА N» при старте и «ВОЛНА N ЗАЧИЩЕНА» при зачистке (сам исчезает через 1,8 с) |
| Оставшиеся противники | «ОСТАЛОСЬ K» + тонкая полоса прогресса волны; «ПОДГОТОВКА» до старта, «ЗАЧИЩЕНА» после |
| Центральный прицел | Тонкий крест (как в M0) |
| Подтверждение попадания | Четыре штриха вокруг прицела: белые — попадание, золотые — в голову, красные и крупнее — убийство; анимация перезапускается на каждом попадании |
| Скрытие мини-карты | Настройки → HUD → «Мини-карта» (сохраняется) |

### Архитектура
- **`src/sim/game-state.js` — отдельная модель состояния** (без DOM и Three.js): здоровье, оружие (магазин, запас,
  перезарядка), волна (номер, осталось, всего, фаза), подтверждение попадания. Изменения — только через методы
  (`damage`, `heal`, `setAmmo`, `setReload`, `completeReload`, `setWave`, `enemyKilled`, `registerHit`), каждое
  порождает событие (`health`, `ammo`, `reload`, `wave`, `waveCleared`, `hit`).
- **`src/ui/game-hud.js`** только читает модель и слушает события. Правил игры в нём нет.
- **Подключение M1.3+ без переписывания HUD:** оружие будет вызывать `setAmmo / setReload / completeReload /
  registerHit`, враги — `damage / enemyKilled / setWave`. Интерфейс уже реагирует на эти вызовы.
- Фиктивных врагов и стрельбы нет. Значения меняются только из **тестового режима `?debug=1`**: кнопка **DBG**
  (вверху по центру, только во время игры) открывает панель «HP / Патроны / Волна / Попадание». Без `?debug=1`
  ни панели, ни тестового доступа нет (проверено тестом).

### Мобильная версия и ПК
- Все новые панели (здоровье, патроны, волна) входят в **редактор HUD из M1.1**: перетаскивание, размер, общий
  размер и прозрачность, «Стандарт», сохранение.
- **Два профиля раскладки**: сенсорный и ПК. На ПК — классические углы (здоровье слева внизу, патроны справа внизу,
  волна сверху по центру, мини-карта слева сверху); на телефоне низ занят джойстиком и кнопками, поэтому здоровье
  сверху слева, волна сверху по центру, патроны снизу по центру. Изменения на телефоне не трогают раскладку ПК и наоборот.
  Раскладка M1.1 автоматически переносится в сенсорный профиль.
- **Панели не перехватывают касания**: палец, попавший на здоровье/мини-карту (слева), становится джойстиком
  движения; на волну/патроны (справа) — обзором. Управление 2–4 пальцами работает поверх панелей.
- Кнопка паузы теперь — неподвижное препятствие: элементы не могут её перекрыть ни в игре, ни в редакторе.
- Панель редактора сама выбирает место, где не закрывает элементы HUD.
- Информационные панели остаются видимыми не менее чем на 70 % даже при низкой прозрачности кнопок — для читаемости.
- На ПК панели пересчитываются при изменении размера окна (проверено от 640×480 до 2560×1080).

## Ограничения
- **iOS Safari не тестировался** — только Chromium (ПК и эмуляция iPhone 11 / 14 Pro Max). Safe area — имитация;
  анимации (пульсация, виньетка) и шрифт («Avenir Next Condensed» на iPhone, запасной на других системах) в Safari
  могут выглядеть немного иначе.
- Значения HUD пока меняются только в тестовом режиме — настоящих врагов и оружия ещё нет (это M1.3–M1.5).
- Счётчик FPS (включён по умолчанию) не входит в раскладку и на очень узких экранах может соседствовать с панелью
  волны; его можно выключить в настройках «ГРАФИКА».
- Цифры производительности из headless Chromium не показательны для iPhone.

## Как проверить
ПК: `python3 -m http.server 8000` → `http://localhost:8000/prototype-3d/?debug=1` → «Играть» → кнопка **DBG** вверху.
Нажимайте «−35», «15», «−1», «0 в маг.», «перезар.», «старт», «−1 враг», «след.», «хит», «в голову», «убийство».
Пауза → «Расставить HUD» — двигать панели мышью.

iPhone: тот же адрес по IP компьютера (см. README), горизонтально. Проверить:
1. Панели не мешают управлению: начинайте движение и обзор прямо с панелей здоровья и патронов.
2. В DBG: «15» — красная пульсация и виньетка читаются, но не мешают обзору.
3. Редактор: передвинуть панели и кнопки, перезагрузить — сохранилось.
4. Панели не попадают под вырез и полосу «Домой».
5. Читаемость цифр на солнце / при низкой яркости.
