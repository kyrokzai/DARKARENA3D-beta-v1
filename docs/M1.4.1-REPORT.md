# Этап M1.4.1 — исправление прыжка (мобильная регрессия)

Ветка: `claude/m1.4.1-mobile-jump` (от тега `m1.4`) · Тег: `m1.4.1` · Основная игра BUILD 1.1–1.3 не изменялась.

## 1. Причина неисправности

Прыжок не «сломался» — его **никогда не было в симуляции**. Кнопка ПРЫЖОК появилась в M1.1 как
заготовка (`future: true` в `ui/hud-layout.js`, «механика позже»): касание корректно доходило до
`InputState` (`actions.jump`, счётчик `presses.jump`), но:

- у игрока не было вертикальной оси (нет высоты, скорости по вертикали, гравитации, приземления);
- ни одна система симуляции не читала `presses.jump`;
- камера стояла на постоянной высоте глаз 1,6 м;
- на ПК клавиша Space только блокировала прокрутку страницы.

Поэтому на iPhone нажатие «ничего не делало». Мультитач, роли пальцев и раскладка HUD работали правильно
(это подтверждали тесты M1.1/M1.2) — проблема была не во вводе.

## 2. Исправление

| Файл | Изменение |
|---|---|
| `src/config.js` | `GRAVITY` 22 м/с², `JUMP_SPEED` 6,6 м/с (высота ≈ 1,0 м, в воздухе ≈ 0,6 с), `JUMP_BUFFER` 0,12 с |
| `src/sim/player.js` | высота `z`, скорость `vz`, `onGround`, шаг вертикали с гравитацией и приземлением; счётчики `jumps`/`landings` |
| `src/sim/game.js` | прыжок по **фронту нажатия** (`presses.jump` изменился с прошлого тика) — тап короче тика не теряется, удержание не повторяет прыжок; после паузы/потери фокуса счётчик синхронизируется, поэтому нажатие перед паузой не «выстреливает» после неё |
| `src/sim/weapons/weapon-system.js` | выстрел из глаз с учётом высоты прыжка (баллистика, урон, темп не менялись) |
| `src/render/renderer.js` | камера поднимается на высоту прыжка (с интерполяцией между тиками) |
| `src/render/weapons/viewmodel.js` | без шагового покачивания в воздухе; оружие слегка отстаёт по вертикали и «проседает» при приземлении |
| `src/input/desktop.js` | ПК: Space = прыжок |
| `src/ui/hud-layout.js`, `src/ui/settings.js`, `src/config.js` | кнопка ПРЫЖОК больше не «будущая»; подпись настройки уточнена |

Горизонтальная скорость, радиус столкновения и остальные характеристики движения не менялись (в прыжке
управление в воздухе то же, что на земле). Стены в арене во всю высоту — запрыгнуть на них нельзя.

## 4. Проверка на iPhone

Ссылка: `https://kyrokzai.github.io/DARKARENA3D-beta-v1/test/m1.4.1/` (Safari, горизонтально).
1. ИГРАТЬ → один короткий тап по ПРЫЖОК — камера поднимается и опускается.
2. Держать ПРЫЖОК — только один прыжок.
3. Левый джойстик вперёд + правый палец ведёт обзор + ОГОНЬ + ПРЫЖОК — всё одновременно.
4. Пауза во время прыжка → ПРОДОЛЖИТЬ — игрок приземляется, лишнего прыжка нет.
5. Свернуть Safari с зажатой кнопкой, вернуться — кнопка не «залипла».
6. Пауза → РАССТАВИТЬ HUD → перенести ПРЫЖОК → Готово — кнопка работает на новом месте.
