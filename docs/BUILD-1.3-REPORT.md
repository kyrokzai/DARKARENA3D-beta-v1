### Ограничения проверки
- Chromium ≠ Safari: эмуляция не воспроизводит зум Safari, safe area и поведение ползунков iOS.
  Поэтому обязательна проверка на реальном iPhone (ниже).
- В Chromium касание дорожки ползунка сразу меняет значение. Если на iPhone прокрутка, начатая на ползунке,
  будет менять настройку — сообщите, исправим (например, прокрутка только по левой колонке подписей).
- Не исправлено в этом билде (вне объёма): safe area для кнопок, мёртвая зона джойстика, чувствительность,
  не зависящая от размера экрана. Это пойдёт в мобильный этап.

## Проверка на реальном iPhone (5–10 минут)

Откройте ссылку на 1.3 (см. раздел GitHub Pages) в Safari. Если видите старую версию — добавьте к адресу `?v=2`.
Запишите модель iPhone и версию iOS.

1. **Поворот.** Держите вертикально — появляется «Поверни iPhone». Поверните горизонтально. Начните «Тренировка → Начать выживание». Во время игры поверните вертикально и обратно — игра должна быть на паузе.
2. **Главная ошибка.** Встаньте лицом к стене, двигайте джойстик строго вправо/влево — игрок идёт боком вдоль стены, а не вперёд/назад. Пройдите вдоль стен, колонны и в углы — стены не «плывут» и не искажаются, игрок не застревает.
3. **Зум.** Быстро тапните дважды: по арене, по кнопке ОГОНЬ, по джойстику, по пустым углам экрана, по мини-карте. Попробуйте щипок двумя пальцами по арене. Страница не должна увеличиваться.
4. **Мультитач.** Одновременно: джойстик левым пальцем, обзор правым, затем третьим пальцем ОГОНЬ. Всё работает вместе.
5. **Залипание.** Держите джойстик и ОГОНЬ, свайпните сверху (Центр уведомлений) или переключитесь в другое приложение, вернитесь. Игра на паузе, после «Продолжить» никто не бежит и не стреляет сам.
6. **Меню.** Пауза → Настройки. Прокрутите пальцем до конца — видны «Расставить кнопки», «Сбросить расположение», «Сохранить настройки». Измените чувствительность, нажмите «Сохранить». Проверьте: прокрутка, начатая на ползунке, не меняет его значение.
7. **Расстановка кнопок.** «Расставить кнопки» → перетащите кнопки → «Готово». Перезагрузите страницу — расположение сохранилось.
8. **Двойной тап в меню.** В меню кнопки нажимаются с первого раза, двойной тап по кнопкам меню не мешает.

Что прислать: номер пунктов, где что-то не так, модель iPhone/iOS, по возможности запись экрана.

## Предложение: как безопасно сделать 1.3 основной версией сайта

Предполагается, что GitHub Pages публикует ветку `main` из корня (проверьте Settings → Pages).

**Шаг 1 — предпросмотр без изменения production.** Pull Request из ветки в `main`, который **не трогает `index.html`**:
он добавляет `DARK_ARENA_1_3.html` (а также `tests/`, `docs/`, `.claude/`, `CLAUDE.md` — игрокам не видны,
файлы безвредны). Игроки по-прежнему получают 1.1, а вы проверяете 1.3 на iPhone по адресу
`https://kyrokzai.github.io/DARKARENA3D-beta-v1/DARK_ARENA_1_3.html`.

**Шаг 2 — переключение (только после вашего подтверждения пунктов 1–8).** Отдельный маленький PR:
- `index.html` ← содержимое BUILD 1.3;
- старые сборки остаются доступными: `DARK_ARENA_1_2_GeometryFix.html` уже есть, 1.1 сохраняется как `builds/DARK_ARENA_1_1.html`;
- тег `build-1.3` на коммите переключения.

**Откат:** revert PR шага 2 (или вернуть `index.html` из тега `build-1.2`) — Pages обновится за 1–2 минуты.
Настройки игроков не потеряются: ключ хранения не менялся.
