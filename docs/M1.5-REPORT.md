## 1. Заражённый «THE HOLLOW»

Процедурная модель (`render/enemies/hollow-model.js`) — без внешних ассетов и генераторов:

- рост ≈ 1,9 м в бинд-позе (≈ 1,8 м в сутулой стойке); истощённое тело с рёбрами, впалым животом, позвоночником;
- сутулая спина и вытянутая шея (поза задаётся анимацией), асимметрия: опущенное левое плечо, наклон головы,
  оторванный рукав только на правой руке, штанины порваны на разной высоте, левая нога шагает короче;
- череп вытянут назад, глубоко посаженные тёмные глазницы, впалые щёки, узкий подбородок, отвисшая челюсть;
  **очень слабое красное свечение глаз** — только эмиссия материала (без источника света);
- серо-бледная кожа с тёмными заражёнными пятнами, прожилками и пятнистостью (вершинные цвета,
  детерминированный шум), тёмные кисти и стопы; рваная тёмная одежда с неровными краями;
- деформированные кисти: узкая ладонь, 4 удлинённых пальца по 3 сустава, загнутых как когти, с тёмными «когтями».

Технически: один `SkinnedMesh` на материал (кожа, лохмотья, глаза) → **3 вызова отрисовки на заражённого**,
21 кость, **5 848 треугольников**; геометрия и материалы создаются один раз и общие для всех экземпляров
(у экземпляра только свои кости). Модель отделена от логики (sim ничего не знает о Three.js).

Скриншоты: `docs/m1.5/m15_viewer_front.png`, `_profile`, `_back`, `_face`; просмотрщик
`prototype-3d/tools/infected-viewer.html` (`?anim=walk&t=1.2`).

## 2. Анимации (`render/enemies/hollow-anim.js`)

Процедурные, непрерывные, слоями; без клипов и без аллокаций в кадре:

| Состояние | Что происходит |
|---|---|
| IDLE | покачивание и дыхание, медленные «поисковые» повороты головы, редкие подёргивания |
| WALK | неровная походка (левая нога короче), перенос веса через таз, руки болтаются |
| RUN | сильный наклон вперёд, руки тянутся к игроку, длиннее шаг |
| ALERT | рывок корпуса, голова дёргается, челюсть раскрыта (крик) |
| ATTACK | правая лапа: замах вверх-назад → удар вниз через корпус → дотяжка; корпус скручивается, выпад |
| HIT | корпус отбрасывает от направления выстрела; при попадании в голову голова отдельно запрокидывается |
| DEATH | подкашиваются колени → падение назад (если стреляли спереди) или вперёд, руки раскидываются по полу; перед удалением тело уходит в пол |

**Без скольжения ног:** фаза шага считается от реально пройденного расстояния, амплитуда шага подобрана под
длину шага (`stride = 4·L·sin A`). Тест: смещение опорной стопы < 25 % от пройденного пути
(измерено ≈ 12 %).

Видео: `docs/m1.5/m15_animations.mp4` (все состояния), `docs/m1.5/m15_gameplay.mp4` (бой).

## 3. ИИ (`sim/enemies/infected.js`, чистый JS)

Конечный автомат: **IDLE → ALERT → CHASE ⇄ ATTACK → RECOVER → CHASE**, любое → **DEAD**.

- **Обнаружение:** радиус 15 м + прямая видимость по сетке карты (DDA); стены блокируют. Проверка раз в 0,2 с,
  со сдвигом по фазе у разных заражённых. Выстрел в заражённого всегда его «будит».
- **Преследование:** если коридор до игрока свободен для тела (радиус 0,3 м) — прямо; иначе по **общему
  flow field** (Дейкстра по 8 направлениям без срезания углов, ≤ 256 клеток), который пересчитывается
  **только когда игрок переходит в другую клетку** — один на всех заражённых. Поворот ограничен (5,5 рад/с),
  разгон/торможение, расталкивание друг от друга, скольжение вдоль стен. Navmesh не понадобился.
- **Атака:** на 1,5 м останавливается и бьёт; урон наносится **только в момент удара** (42 % замаха ≈ 0,36 с),
  только если игрок ещё в досягаемости (1,75 м), перед заражённым (±37,5°) и в прямой видимости; **ровно
  один раз за замах**; затем cooldown 1,2 с. От удара можно уйти.
- Скорость движения не зависит от FPS (фиксированный шаг 60 Гц, детерминизм проверен тестом).

Все параметры — данные в `sim/enemies/infected-defs.js`:

| Параметр | Значение |
|---|---|
| Здоровье | 100 HP |
| Урон RAVEN голова / корпус | 50 / 25 (из `weapons/defs.js`, не менялись) |
| Урон удара заражённого | 15 HP |
| Обнаружение | 15 м (с прямой видимостью) |
| Дистанция атаки / досягаемость удара | 1,5 м / 1,75 м |
| Cooldown атаки | 1,2 с |
| Шаг / бег | 1,1 / 4,2 м/с (игрок 5,5 м/с — можно оторваться) |
| Тело остаётся | 5 с |

## 4. Бой, убийства, волна

- Зоны попадания: голова (сфера, чуть впереди — заражённый сутулится) и корпус (цилиндр); совпадение с
  анимированной головой проверено (≤ 0,12 м).
- Попадания идут через существующий hitscan и события (`shot`, `targetHit`, `hit`); кровавые брызги — один
  общий буфер частиц (160), маркер попадания/хедшота/убийства из M1.3.
- Смерть: DEAD, атаки прекращаются, тело не принимает попаданий, **убийство считается один раз**
  (`GameState.kills`, событие `kills`), через 5 с тело удаляется, экземпляр модели возвращается в пул.
- **Волна 1** (`sim/waves/wave-defs.js`): 3 HOLLOW, появляются по одному (2,5 с подготовки, затем каждые 1,6 с)
  на свободном полу, не ближе 9 м и не в конусе ±55° перед игроком в пределах 16 м; после убийства всех —
  **WAVE 1 COMPLETE**. Бесконечных волн нет.
- **Смерть игрока:** экран «ВЫ ПОГИБЛИ» (волна, убито), ЗАНОВО (полный перезапуск: HP, патроны, убийства,
  волна 1) и ГЛАВНОЕ МЕНЮ.

## 5. HUD и звук

- Все значения — из GameState: здоровье, номер волны, «ОСТАЛОСЬ N», **счётчик убийств** (новое поле в панели
  волны), маркер попаданий, баннер WAVE 1 COMPLETE, экран смерти. Параллельной модели нет; раскладка и
  настройки HUD M1.1/M1.2 сохранены.
- Звук (Web Audio, оригинальный синтез, без сэмплов): шаги заражённых (по фазе походки), хрип/дыхание
  ближайшего, крик обнаружения, рык и свист удара, вскрик при ранении, предсмертный хрип, удар по игроку.
  **Позиционирование:** стерео-панорама + затухание и приглушение высоких частот с расстоянием (пул из 8
  цепочек, без HRTF — дёшево для iPhone). Разблокировка звука в Safari — как в M1.3 (первый жест).

Оптимизации: общая геометрия/материалы; пул экземпляров; фиксированный буфер частиц; общий flow field

подтверждены** — нужна проверка на устройстве. Если просядет, первые кандидаты (тени уже отключены):
снизить сегменты головы/туловища (≈ −30 % треугольников), уменьшить `renderScale`.

## 9. Найденные проблемы и их статус

Исправлено в ходе работы:
1. Вершинные цвета кожи задавались в sRGB, а шейдер ждёт линейные — пятна заражения пропадали (контраст
   «съедался»). Исправлено переводом в линейное пространство.
2. Челюсть торчала отдельной «губой», плечевые суставы — крупные светлые шары, глаза светили слишком ярко —
   уменьшено, затемнено, свечение 0,32.
3. После смерти рука торчала вверх, ноги висели в воздухе — руки и ноги теперь ложатся на пол.
4. В тестах стрельба «удержанием на тик» давала 2–3 выстрела при медленных кадрах — тест переведён на тап
   короче тика (механика оружия не менялась).
5. По независимому ревью: (а) направление падения тела зависело от FPS (> 90 к/с — всегда назад) — теперь
   фиксируется один раз при смерти; (б) экран смерти можно было пропустить паузой в 0,7 с задержки — теперь
   не пропускается (тест добавлен); (в) перезапуск в `?debug=1` оставлял в HUD данные волны — `restart({waves})`;
   (г) мелкие аллокации в кадре (массивы в анимации, объект в `rel`, замыкание в шаге) — убраны;
   (д) ссылки на удалённых заражённых в карте шагов — очищаются.
6. В README M1.4 пропал заголовок «Structure» — восстановлен.

Известные ограничения (не исправлено):
- Модель процедурная, «low/mid-poly»: конечности — трубки, на швах видны стыки, одежда без физики ткани;
  до уровня скульптурной модели далеко. Лицо читается вблизи, в тёмной арене на расстоянии — в основном
  силуэт и глаза.
- Падение тела не учитывает стены: у стены труп может частично войти в неё.
- После обнаружения заражённый преследует игрока по flow field даже без прямой видимости («чует» его) — это
  решение для волнового выживания; обнаружение (первое) — только с прямой видимостью.
- Хитбоксы не следуют за анимацией атаки/реакции (остаются в стойке).
- Позиционный звук — стерео-панорама, без высоты и HRTF.
- **iPhone не проверялся**: мобильные проверки — эмуляция Chromium. Производительность на устройстве не
  подтверждена.

## 10. Сравнение с M1.4

M1.4 — оружейный прототип: полигон с мишенями. M1.5 — играбельный шутер: волна из трёх заражённых,
которые обнаруживают, преследуют, обходят препятствия и атакуют; здоровье, смерть игрока и перезапуск;
счётчик убийств; звук противников. Плюс исправленный прыжок (M1.4.1).
