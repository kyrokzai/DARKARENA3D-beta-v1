## M3.0.1 — «плывущая текстура» у ходока и громилы

Причина — веса вершин: прежний автоматический риг оставил ~590 вершин с жёстким весом 1.0 и снял ~7 600 связок
вершина–кость → резкие ступеньки весов → треугольники на плечах / руках / торсе растягивались в 100–1500 раз.
Исправление: скелет героя ставится в позу каждого зомби (сдвиг + поворот + растяжение кости к подогнанному суставу),
веса героя переносятся с этой поверхности на зомби, сросшиеся мосты рука/бедро разрезаются, 4 прохода сглаживания весов
с учётом швов UV, без жёстких назначений; атака громилы — подъём рук 140° (было 175°) с долей ключицы.
Худшее растяжение верхней части тела: громила Attack 1500 → 45, ходок Attack 326 → 86, ходок Run (Spine) 815 → 79.
Мутант и герой не менялись. Сравнение: `docs/m3.1/skinning_55deg.png`, `docs/m3.1/skinning_closeup.png`.

экспортировал через Blender glTF I/O 4.3.47) и их собственные `texture_emissive.png`. Исходники не изменялись (SHA-1 всех
