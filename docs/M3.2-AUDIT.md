→ `GameState` (rule 8) → `topdown/hud.js` (DOM) · `topdown/renderer.js` (camera 55°, M2.0 level builder + 1.5 m cut,
impacts, tracers, flash) · `topdown/hero.js` (GLB + RAVEN + 2-bone arm IK, Idle / Walk / Run / DodgeRoll / Death) ·

`topdown/models.js` (GLTFLoader + meshopt). Quality: `render/quality.js` (performance / balanced / quality).

- FPS regression flakes under load (m1.2 / m1.3 reload timing) — re-run sequentially, compare with the M2.0 base.
