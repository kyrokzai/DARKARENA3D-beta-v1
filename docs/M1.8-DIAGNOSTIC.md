# M1.8 — диагностика «мыла» и темноты M1.7

Измерено в Chromium с эмуляцией устройств (Playwright `devices`), базовая M1.7 (тег `m1.7`), настройки по умолчанию.
Сравнительные кадры — без увеличения, 1:1 к физическим пикселям: `m1.8/diag_crop_*_1to1.png`, данные — `m1.8/diag_resolution.json`.

## 1. Внутреннее разрешение (главная причина)
`renderer.js`: `pixelRatio = min(devicePixelRatio, 2) × renderScale`, `renderScale` по умолчанию **0,75**
(и он сохранён в localStorage у всех, кто открывал прежние сборки).

| Устройство (landscape) | CSS | DPR | drawing buffer M1.7 | физически | по оси | по пикселям |
|---|---|---|---|---|---|---|
| iPhone 11 | 800×364 | 2 | 1200×546 | 1600×728 | 75 % | **56 %** |
| iPhone 14 Pro Max | 814×380 | 3 | 1221×570 | 2442×1140 | 50 % | **25 %** |

На iPhone с DPR 3 (12/13/14/15 Pro, Pro Max, mini) игра рисуется в четверть пикселей экрана, на DPR 2 — чуть больше
половины. Даже `renderScale = 1` на DPR 3 даёт только 67 % по оси — из-за ограничения DPR ≤ 2.

## 2. Растяжение canvas «по ближайшему пикселю»
`style.css`: `#view { image-rendering: pixelated / crisp-edges }`. Уменьшенный буфер растягивается до экрана без
сглаживания → ступенчатые края оружия, прицела и силуэтов (кадр A). При буфере = физическому размеру правило не влияет.

## 3. Нет сглаживания
`new WebGLRenderer({ antialias: false })` — MSAA выключен; края геометрии «лесенкой» (сравнить кадры D и E).

## 4. Текстуры с очень низкой плотностью и фильтром «ближайший»
Стены 32×48 px на грань 2×3 м (16 текселей/м), пол 16×16 на клетку 2 м (8 текселей/м), `magFilter = Nearest`,
анизотропия 1 — наследие «пиксельного» стиля рейкастера. На стене в 3 м один тексель ≈ 15 физических пикселей
iPhone 14 Pro Max, на полу ≈ 30: крупные квадраты, которые на маленьком экране читаются как размытые пятна.
Атлас заставы — 128 px на тип поверхности.

## 5. Заражённые — детали только в вершинах
Цвет кожи/одежды — вершинные цвета (≈ 7k треугольников на модель), плюс одна тайловая карта нормалей 128 px;
нет карты цвета/шероховатости → складки, швы, черты лица не могут быть мельче шага сетки. Это даёт «процедурный» вид.

## 6. Темнота
Мир рисуется без tone mapping (оружие — ACES ×1,35), средняя яркость кадра M1.7 ≈ 23/255 (11 фиксированных ракурсов).
Полутона уходят в чёрный; на телефоне с автояркостью детали в тени не видны.

## Что не является причиной
- CSS-размер canvas = размер окна (100 %), без дополнительного масштабирования страницы.
- Цветовые пространства текстур корректны (цвет — sRGB, нормали — Linear); mip-уровни включены.

## Вывод для M1.8
Порядок исправлений: (1) профили качества с бюджетом пикселей и учётом реального DPR, (2) MSAA, (3) убрать
`pixelated`, (4) текстуры окружения в разы плотнее с линейной/анизотропной фильтрацией, (5) общий tone mapping и
подъём полутонов, (6) заражённые с картами цвета/нормалей/шероховатости. Стоимость (1)–(2) на реальном iPhone
нужно подтвердить на устройстве; в программном Chromium она не измерима.
